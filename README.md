# Web Calculator
this is a lightweight, aesthetically pleasing calculator built with a modern Glassmorphism UI. It combines smooth CSS transitions with the power of `Math.js` to provide a seamless mathematical experience wrapped in a cyberpunk-inspired interface.

---

##  Features

*   **Glassmorphism UI:** Frosted glass effect with backdrop filters and subtle glows.
*   **Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.
*   **Intelligent Logic:** Powered by `math.js` to handle complex expressions.
*   **Micro-interactions:** Smooth hover lifts, active scaling, and focus-aware text shadows.
*   **Tactile Feedback:** Built-in "DE" (Delete) and "AC" (All Clear) functions for precision editing.
---

 ## Problem

Many basic calculator web apps:

*  Have outdated UI design
*  Lack smooth user interaction
* Are not responsive on mobile devices
* Provide a boring and unengaging experience
---
## Solution

This project solves these issues by:

* Modern glassmorphism-based UI design
* Smooth and interactive user experience
* Fully responsive layout (mobile-first approach)
* Clean visual hierarchy for better usability

---


##  Technical Breakdown

### **The Stack**
*   **HTML5:** Structured for accessibility and semantic clarity.
*   **CSS3 (Advanced):** Utilizes `radial-gradient`, `backdrop-filter`, and `media queries` for that premium look.
*   **Math.js Library:** Used for robust calculation handling (via CDN).

### **Code Highlights**
*   **Responsive Grid:** Custom calculations for button widths on mobile screens.
*   **Error Handling:** `try...catch` blocks to prevent the UI from breaking on invalid mathematical syntax.
