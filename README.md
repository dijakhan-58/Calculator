# 🌌 LucidCalc: Glassmorphism Web Calculator

![GitHub License](https://img.shields.io/badge/license-MIT-blueviolet)
![Tech Stack](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20JS-informational)

**LucidCalc** is a lightweight, aesthetically pleasing calculator built with a modern Glassmorphism UI. It combines smooth CSS transitions with the power of `Math.js` to provide a seamless mathematical experience wrapped in a cyberpunk-inspired interface.

---

## ✨ Features

*   **Glassmorphism UI:** Frosted glass effect with backdrop filters and subtle glows.
*   **Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.
*   **Intelligent Logic:** Powered by `math.js` to handle complex expressions.
*   **Micro-interactions:** Smooth hover lifts, active scaling, and focus-aware text shadows.
*   **Tactile Feedback:** Built-in "DE" (Delete) and "AC" (All Clear) functions for precision editing.

## 🚀 Quick Start

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/lucidcalc.git
    ```
2.  **Open the project:**
    Simply double-click `index.html` or use Live Server in VS Code.

3.  **Dependencies:**
    The project uses a CDN for `math.js`. Ensure you have an active internet connection or download the library locally.
    ```html
    <script src="https://cdnjs.cloudflare.com/ajax/libs/mathjs/11.8.0/math.js"></script>
    ```

---

## 🎨 Customization

Want to change the vibe? Check the `style.css` file:

*   **Change the Glow:** Edit the `background: radial-gradient(...)` in the `body` selector.
*   **Adjust Translucency:** Modify the `rgba(255, 255, 255, 0.03)` values in the `#calculator` ID.
*   **Button Shapes:** Tweak the `border-radius: 20px` to `50%` for a circular button look.
